# 시험(Examen) 랜덤 출제 · 합격 기준 안내 · 부정행위 방지(단방향 최종 제출) 구현 계획

사용자의 4가지 요청 사항을 한국어(`ko`)와 스페인어(`es`) 인터페이스에 완벽히 분리하여 반영합니다.

---

## 1. 주요 변경 사항

### ① 시험 탭 진입 시마다 매번 랜덤 순서로 출제
- 상단 내비게이션에서 **시험(`Examen`)** 탭을 클릭하여 진입할 때마다(또는 시험 중 일차를 변경할 때마다) Fisher-Yates 셔플 알고리즘을 통해 해당 일차 시험 문항(10문항)의 순서를 매번 새롭게 무작위로 섞습니다.
- 기존의 수동 순서 토글 버튼(`순서 섞기` / `기본 순서`)은 제거하고 항상 무작위 순서로 출제되도록 고정합니다.
- **집중공부(`Estudio Intensivo`) → 3. 미니 시험**에 진입할 때에도 북마크된 문항들이 매번 무작위 순서로 출제되도록 동일하게 적용합니다.

### ② 정답 확인 후 '시험 다시보기' 클릭 시 새로운 랜덤 순서로 재시작
- 시험 최종 제출(정답 확인) 후 결과 화면에 **처음부터 다시 시험보기 (`Volver a realizar todo el examen`)** 버튼을 배치합니다.
- 이 버튼을 클릭하면 기존 입력 답안과 채점 결과를 모두 초기화하고, **문항 순서를 다시 새롭게 랜덤으로 섞어** 1번 문항부터 시험을 재시작합니다.

### ③ 시험 시작 화면 상단에 합격 기준(80점) 안내 표시
- 시험 탭에 들어가 문제를 풀 때 시험 카드 최상단에 눈에 잘 띄는 안내 배너를 고정 표시합니다:
  - **한국어 (`ko`)**: `"시험 합격 기준은 80점 입니다."`
  - **스페인어 (`es`)**: `"El criterio de aprobación del examen es de 80 puntos."`

### ④ 부정행위 방지를 위한 단방향 시험 진행 ('다시 입력' 및 이전 이동 제거)
- **메인 시험(`시험` 탭)**:
  - 문항 번호(`1 ~ 10`) 인디케이터의 클릭 이동 기능을 제거하여 이전 문항이나 다른 문항으로 돌아갈 수 없는 진행 상태 표시(배지)로 변경합니다.
  - 하단의 **`이전` (`Anterior`) 버튼을 제거**합니다.
  - 각 문항에서 답안을 작성하고 **`다음` (`Siguiente`)** 버튼을 누르면 다시는 이전 문항으로 돌아가 수정할 수 없으며, 마지막 문항에서 **`최종 제출 및 정답 확인` (`Entregar y verificar respuestas`)** 버튼으로 한 번에 채점합니다.
- **집중공부 미니 시험(`3. 미니 시험` 탭)**:
  - 문제별 개별 채점 및 **`다시 입력` (`Reintentar`) 버튼을 완전히 제거**합니다.
  - 메인 시험과 동일하게 1번부터 끝까지 단방향으로 한 번씩만 답안을 입력하고, 마지막 문항에서 한 번에 최종 제출하여 80점 기준 합격/불합격 배너와 전체 결과를 확인하도록 통일합니다.

## 2. 수정 대상 파일
- `/src/data/i18n.ts`: 한국어·스페인어 상단 합격 기준 안내 문구(`"시험 합격 기준은 80점 입니다."` / `"El criterio de aprobación del examen es de 80 puntos."`) 및 시험 다시보기/최종 제출 다국어 키 추가·정비
- `/src/App.tsx`: 시험 탭 진입 및 다시보기 클릭 시 Fisher-Yates 랜덤 셔플 적용, 상단 80점 합격 기준 배너 추가, 번호 클릭 및 '이전' 버튼 제거(단방향 진행), 결과 화면 내 '시험 다시보기(랜덤 재시작)' 버튼 구현
- `/src/components/IntensiveStudySection.tsx`: 집중공부 내 '3. 미니 시험'에서도 '다시 입력' 버튼을 제거하고 랜덤 순서 + 단방향 진행 + 마지막 일괄 최종 제출 방식으로 통일
