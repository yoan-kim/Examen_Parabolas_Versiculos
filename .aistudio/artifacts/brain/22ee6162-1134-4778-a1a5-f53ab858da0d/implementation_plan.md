# 비유와 성구 시험 (Parábolas y Versículos) — 기능 고도화 및 모듈화 계획

99개 비유와 증거성구 학습 시스템을 **한국어(`비유와 성구 시험`)**와 **스페인어(`Parábolas y Versículos`)** 전용 인터페이스로 새롭게 정비하고, 유지보수가 쉬운 모듈형 구조(JSON 데이터 · CSS 스타일 · 기능별 컴포넌트 분리), **2단계 정답 확인(뜻 → 성구)**, **성경 원문(개역한글판 / Reina-Valera 1960) 자동 표시**, **집중공부 전용 탭**, 그리고 **고급학습기능(학습팁 노트 · 노트북 모아보기 · 오답/정답률 통계)**을 도입합니다.

---

## 사용자 검토 및 확정 사항 (User Review & Confirmed Decisions)

> [!IMPORTANT]
> 사전 질문에서 확정해주신 아래 3가지 핵심 결정을 바탕으로 전체 설계를 구성했습니다.

- **확정 결정 1 — 스페인어 및 한국어 타이틀**: 한국어 인터페이스는 **`비유와 성구 시험`**, 스페인어 인터페이스는 **`Parábolas y Versículos`**로 표기합니다.
- **확정 결정 2 — `집중공부` 탭 학습 방식**: 상단 네비게이션의 `학습 (10)`, `시험 (10)` 바로 뒤에 **`집중공부`** 탭을 추가하며, 탭 내부에서 **카드 학습**, **타이핑 학습**, **미니 시험** 3가지 모드를 모두 지원합니다.
- **확정 결정 3 — `고급학습기능` 모드 구성**: 우측 상단 `HTML 저장` 버튼을 제거하고 **`고급학습기능`** 전환 버튼(마우스 오버 시 설명 툴팁 팝업 표시)을 배치합니다. 활성화 시 전체 페이지가 고급학습 모드로 전환되며 **(1) 정답 확인 후 나타나는 문제별 `학습팁 노트` 작성·저장**, **(2) 작성한 노트를 한눈에 모아보는 `노트북 모아보기`**, **(3) 문제별 누적 오답 횟수 및 정답률 통계**가 함께 제공됩니다.

## 1. 핵심 개념 및 개요 (Overview & Core Concept)

- **무엇을 하는 앱인가**: 20개 장 · 99개 성경 비유 개념과 증거성구를 한국어와 스페인어(라틴아메리카 에콰도르 발음 `es-EC` 지원)로 완벽히 분리하여 학습하고 시험 볼 수 있는 체계적인 학습 플랫폼입니다.
- **핵심 가치**:
  1. **단계적 인출(Progressive Recall)**: 뜻을 먼저 떠올린 뒤 성구를 한 번 더 생각하게 하는 2단계 가림막과, 확인 직후 바로 읽을 수 있는 성경 원문(개역한글판 / Reina-Valera 1960)으로 암기 효과를 극대화합니다.
  2. **약점 집중 공략**: 학습 및 시험 중 체크한 문항만 따로 모아 카드·타이핑·시험으로 반복 훈련할 수 있는 전용 `집중공부` 공간을 제공합니다.
  3. **개인화된 고급 학습**: 정답을 끝까지 확인한 문항에 나만의 암기 연상법·학습팁을 기록하고, 문제별 정오답 이력을 추적합니다.

## 2. 사용자 경험 및 시각 디자인 (User Experience & Visual Design)

### 주요 사용자 흐름 (Key User Flows)

1. **초기 언어 선택 게이트 (`한국어` / `Español`)**
   - 앱 진입 시 타이틀 **`비유와 성구 시험`** / **`Parábolas y Versículos`**와 함께 언어를 선택하며, 선택 이후 모든 UI·안내문·성경 원문은 해당 언어로만 철저히 분리되어 표시됩니다.
2. **2단계 정답 확인 (1. 카드 학습 모드)**
   - **초기 상태**: 뜻(의미) 영역과 증거성구 영역이 각각 불투명한 흰색 카드(**`정답 확인`** / **`Ver respuesta`**)로 완전히 덮여 있습니다.
   - **1차 클릭 (`정답 확인`)**: 비유의 **뜻(의미)**이 공개됩니다. 증거성구가 있는 문항은 성구 영역이 여전히 흰색 카드(**`성구 정답 확인`** / **`Ver versículo`**)로 가려져 있으며, 증거성구가 없는 문항(`-`)은 1차 클릭만으로 즉시 전체 공개 완료 상태가 됩니다.
   - **2차 클릭 (`성구 정답 확인`)**: 가려져 있던 **증거성구**가 공개되면서 해당 문항의 정답 확인이 완료됩니다.
3. **성경 구절 원문 자동 표시 (개역한글판 / Reina-Valera 1960)**
   - 카드 학습에서 성구까지 모두 열람하거나, 타이핑 학습 및 시험에서 답안 채점을 완료하면 카드 하단에 해당 증거성구의 **성경 원문 박스**가 펼쳐집니다.
   - 한국어 모드에서는 **개역한글판** 원문을, 스페인어 모드에서는 **Reina-Valera 1960** 원문을 절별로 깔끔하게 보여줍니다.
4. **`집중공부` 전용 탭 (`학습 (10)` · `시험 (10)` · `집중공부` · `전체 도감`)**
   - 상단 안내 배너:
     - 한국어: *"학습과 시험 중 '집중공부'로 체크한 문항만 따로 모아 카드·타이핑·미니 시험으로 완벽히 마스터할 수 있는 전용 공간입니다."*
     - 스페인어: *"Espacio exclusivo que reúne las preguntas marcadas para estudio intensivo, permitiéndole dominarlas mediante tarjetas, escritura y mini examen."*
   - 내부에서 **1. 카드**, **2. 타이핑**, **3. 미니 시험**을 자유롭게 전환하며 집중공부 문항만 반복 학습할 수 있습니다.
5. **`고급학습기능` 버튼 및 전용 학습 도구**
   - **마우스 오버 툴팁 팝업**: 우측 상단 `고급학습기능` 버튼에 마우스를 올리면 세련된 플로팅 팝업으로 *"나만의 암기 노트를 기록하는 '학습팁 노트'와 문항별 오답·정답률 분석 등 심화 학습 도구가 포함된 모드입니다."* 안내가 표시됩니다.
   - **전환 시 활성화 기능**:
     - **문제별 `학습팁 노트` 버튼 (7-1)**: 정답(뜻과 성구)을 끝까지 모두 확인하기 전에는 숨겨져 있다가, **정답 확인 또는 채점이 완료된 직후** 성경 원문 아래에 **`+ 학습팁 노트` (`+ Nota de estudio`)** 버튼이 나타납니다. 버튼을 누르면 해당 문제를 쉽게 이해·암기하기 위한 나만의 팁을 작성하고 자동/수동 저장할 수 있는 노트 창이 열립니다.
     - **학습팁 노트북 모아보기**: 상단 바에서 내가 작성한 모든 문제의 학습팁 노트를 한눈에 모아 보고 바로 수정할 수 있습니다.
     - **누적 오답 횟수 및 정답률 표시**: 각 문제 헤더에 나의 누적 시도 대비 정답률(`정답률 80% · 오답 1회`)이 정갈한 텍스트 메타데이터로 표시됩니다.

### 시각 디자인 및 타이포그래피 (Visual Identity & Theme)

- **미학 방향 (Aesthetic Direction)**: 집중력을 높이는 에디토리얼 학습지 스타일 (Editorial Academic Workspace).
- **색상 팔레트 (60-30-10 원칙)**:

  - **10% 강조 색상**: 기본 학습 모드에서는 딥 에메랄드 그린 (`#14532D`), **고급학습기능** 활성화 시에는 학구적인 딥 인디고/앰버 포인트(`#1E3A8A` / `#B45309`)로 모드 전환을 명확히 인지시킵니다.

## 3. 핵심 설계 결정 및 아키텍처 전략 (Key Product Decisions & Trade-Offs)

- **결정 1 — 단일 HTML 생성기 제거 및 JSON · CSS · 컴포넌트 분리**
  - *선택한 방식*: 기존의 단일 파일 내보내기 방식을 제거하고, 질문 데이터·성경 원문 데이터·다국어 사전을 독립된 **JSON 데이터 파일**로 분리하며, 스타일시트(`CSS`)와 기능별 UI 컴포넌트를 모듈 단위로 구조화합니다.
  - *이유*: 향후 성구 수정, 문항 추가, 디자인 변경, 고급학습기능 확장 시 원하는 데이터나 스타일만 즉시 찾아 직관적으로 수정할 수 있습니다.
- **결정 2 — 99문항 전체 증거성구 원문 데이터베이스 내장 (개역한글판 & Reina-Valera 1960)**
  - *선택한 방식*: 외부 API 호출 지연이나 네트워크 오류 없이 오프라인/즉시 렌더링되도록 99개 문항에 등장하는 모든 증거성구의 **개역한글판** 및 **Reina-Valera 1960** 원문을 구조화된 JSON 사전으로 내장합니다.
  - *이유*: 정답 확인 즉시 0ms 지연으로 정확한 성경 원문을 대조하며 읽을 수 있습니다.

### 상태 및 인터랙션 매핑 (Interactive Component & State Mapping)

1. **2단계 정답 공개 상태 (`revealStageByUid: Record<string, 0 | 1 | 2>`)**
   - `0` (미공개): 뜻과 성구 모두 흰색 카드로 가려짐.
   - `1` (뜻 공개): 첫 번째 `정답 확인` 클릭 시 전환. 해당 문항에 증거성구가 없으면(`verse === '-'`) 자동으로 `2`로 즉시 전환.
   - `2` (완전 공개): 두 번째 `정답 확인` 클릭 시 성구까지 공개되며, 동시에 하단 **성경 구절 원문 박스(개역한글판 / Reina-Valera 1960)**와 (고급학습기능 활성 시) **`학습팁 노트` 버튼**이 렌더링됩니다.
2. **고급학습기능 상태 (`isAdvancedMode: boolean`, `studyNotes: Record<number, { ko: string; es: string }>`, `questionStats: Record<number, { attempts: number; wrong: number }>`)**
   - 우측 상단 `고급학습기능` 버튼에 마우스를 올리면 설명 팝업이 표시되고, 클릭하면 고급학습 모드가 토글됩니다.
   - 정답이 완전히 공개된(`stage === 2` 또는 타이핑/시험 채점 완료) 문항에서 `학습팁 노트` 버튼을 클릭하면 노트 입력창이 열리며, 작성한 내용은 브라우저에 영구 저장됩니다.
