# 32회차(일일 6문항: 신규 3 + 누적 랜덤 복습 3) 개편 및 학습·시험 분리 계획

기존 20일차(10문항: 신규 5 + 복습 5) 구조를 **총 32회차(시험 6문항: 1회차 신규 6문항, 2~32회차 신규 3문항 + 누적 랜덤 복습 3문항)** 체제로 전면 개편합니다. **학습 탭**에서는 복습 없이 해당 회차의 **신규 문항만** 집중 학습하고, **시험 탭**에 들어갈 때마다 및 **시험 리셋**을 누를 때마다 `1회차`부터 `n-1회차`까지의 전체 누적 범위에서 복습 3문항이 매번 새롭게 랜덤 추출되어 출제되도록 구현합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> 질문 응답을 통해 확정된 핵심 설계 기준입니다.

- **전체 32회차 커리큘럼 구성 (총 99문항 100% 유지)**:
  - **1회차**: 신규 6문항 (`Q1~Q6`), 복습 없음 → 학습 6문항 / 시험 6문항
  - **2회차**: 신규 3문항 (`Q7~Q9`) + 1회차(`Q1~Q6`) 중 랜덤 복습 3문항 → 학습 3문항(신규만) / 시험 6문항
  - **3회차**: 신규 3문항 (`Q10~Q12`) + 1~2회차(`Q1~Q9`) 중 랜덤 복습 3문항 → 학습 3문항(신규만) / 시험 6문항
  - **...**
  - **32회차**: 신규 3문항 (`Q97~Q99`) + 1~31회차(`Q1~Q96`) 중 랜덤 복습 3문항 → 학습 3문항(신규만) / 시험 6문항
- **시험 점수 반올림 및 80점 합격 기준 유지**:
  - 6문항 시험 점수를 반올림(`Math.round((정답수 / 6) * 100)`)하여 표기합니다.
  - 6개 중 6개 정답 시 **100점(합격)**, 6개 중 1개 틀릴 시(5개 정답) **83점(합격)**, 2개 이상 틀릴 시(4개 이하 정답, **67점 이하**) **불합격**으로 판정합니다.

## 1. Overview & Core Concept

- **What It Does**:
  1. **학습 탭: 신규 문항 전용**: 학습 탭을 클릭하면 전체/복습 구분 없이 해당 회차의 **신규 문항만** 표시됩니다 (`1회차`는 6문항, `2~32회차`는 3문항).
  2. **시험 탭: 신규 + 누적 랜덤 복습 6문항 & 매번 새로운 복습 추출**: `n회차` 시험에 진입할 때마다, 그리고 **[시험 리셋]** 또는 **[시험 다시보기]**를 누를 때마다 `1회차`부터 `n-1회차`까지의 모든 문항 중 3개를 **매번 새로 랜덤 추첨**하여 해당 회차 신규 3문항과 합쳐 총 6문항을 무작위 순서로 출제합니다.
  3. **'일차' → '회차' 용어 일괄 변경**: 앱 내의 모든 `1일차`, `2일차`, `20일 진도표` 표기를 **`1회차`, `2회차`, ..., `32회차`**, **`32회차 진도표`**(스페인어: `Sesión 1` ~ `Sesión 32`, `Plan de 32 Sesiones`)로 통일합니다.
- **Target Audience / Persona**: 하루 학습 부담을 적정량(신규 3문항 학습, 총 6문항 시험)으로 줄이면서도, 시험 때마다 이전 전 회차 누적 범위에서 계속 바뀌는 랜덤 복습 문제로 장기 기억을 탄탄하게 다지려는 학습자.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **학습 탭 (`학습`) 진입 시**:
     - 상단 필터(`[전체 | 신규 | 복습]`) 없이 곧바로 현재 선택된 회차의 **신규 문항**(`1회차` 6문항, `2~32회차` 3문항)만 카드 또는 타이핑 모드로 학습합니다.
  2. **시험 탭 (`시험 (6)`) 진입 및 [시험 리셋] 클릭 시**:
     - 상단 **[시험 (6)]** 탭을 누르거나 시험 화면 우측 상단 **[시험 리셋]**(또는 결과 화면의 **[시험 다시보기]**)을 누를 때마다 즉시 `1회차 ~ (n-1)회차`의 전체 누적 문항 풀에서 새로운 복습 3문항이 랜덤으로 다시 뽑히고, 해당 회차 신규 3문항과 섞여 1번부터 6번까지 무작위 순서로 배치됩니다.
  3. **32회차 학습 현황판 및 진도표**:
     - 우측 **회차별 학습 현황** 2열 그리드와 상단 회차 드롭다운, 우측 **32회차 진도표**가 모두 `1회차`부터 `32회차`까지 표시되며, 각 회차별 최고점수(`최고 83점`, `최고 100점` 등)가 언어별로 누적 기록됩니다.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 학습 탭과 시험 탭의 역할 명확화**
  - *Chosen Approach*: 학습 탭은 오직 해당 회차의 신규 개념 암기에만 집중하도록 복습 카드를 제외하고, 복습은 시험 탭에서 깜짝 랜덤 테스트 형태로 검증하도록 분리합니다.
  - *Why*: 학습 단계에서 미리 오늘 나올 복습 3문항만 외워서 시험을 보는 패턴을 방지하고, 이전 회차 전체(`1 ~ n-1회차`)에 대한 진짜 실력을 점검할 수 있습니다.
- **Decision 2: 시험 진입·리셋 시마다 복습 문항 동적 재추첨**
  - *Chosen Approach*: 고정된 일일 복습 목록을 재사용하지 않고, 시험 세션을 시작하거나 리셋할 때마다 `sampleRandomIds(learnedPoolIds, 3)`을 새로 호출하여 복습 3문항을 매번 다르게 구성합니다.
  - *Why*: 똑같은 복습 문제만 반복 출제되는 현상을 원천 차단합니다.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:
```
┌───────────────────────────────────────────────────────────────────────────┐
│                   32회차 커리큘럼 엔진 (99문항 100% 유지)                   │
├───────────────────────────────────────────────────────────────────────────┤
│  • 1회차 : 신규 6문항 (Q1~Q6)   │ 복습 0문항                              │
│  • 2회차 : 신규 3문항 (Q7~Q9)   │ 복습 3문항 (1회차 Q1~Q6 중 랜덤)        │
│  • 3회차 : 신규 3문항 (Q10~Q12) │ 복습 3문항 (1~2회차 Q1~Q9 중 랜덤)      │
│  • ...                                                                    │
│  • n회차 : 신규 3문항 (Q(3n+1)~Q(3n+3)) │ 복습 3문항 (Q1~Q(3n) 중 랜덤)   │
│  • 32회차: 신규 3문항 (Q97~Q99) │ 복습 3문항 (1~31회차 Q1~Q96 중 랜덤)    │
└───────────────────┬───────────────────────────────────┬───────────────────┘
                    │                                   │
         [학습 탭 (신규 전용)]                 [시험 탭 (총 6문항 시험)]
                    ▼                                   ▼
┌─────────────────────────────────────┐ ┌───────────────────────────────────┐
│ • 1회차: 신규 6문항만 표시          │ │ • 시험 탭 진입 / 시험 리셋 /      │
│ • 2~32회차: 신규 3문항만 표시       │ │   시험 다시보기 클릭 시마다:       │
│ • 복습 문항 미표시 (신규 학습 집중) │ │   1~(n-1)회차 전체 풀에서         │
│                                     │ │   복습 3문항을 매번 새로 랜덤 추출│
│                                     │ │ • 신규 3 + 복습 3 = 총 6문항 셔플 │
│                                     │ │ • 5/6 정답 시 83점(반올림) 합격   │
└─────────────────────────────────────┘ └───────────────────────────────────┘
```

- **Data Model & State**:
  - `DAY_SCHEDULES`: 총 32개 회차(`day: 1 .. 32`)로 생성하며, `day === 1`은 `newConceptIds: [1..6], reviewConceptCount: 0`, `2 <= day <= 32`는 `startId = 3 * day + 1`, `endId = 3 * day + 3`, `learnedPoolIds = [1 .. 3 * day]`, `reviewConceptCount: 3`으로 정의합니다.
  - `studyCards`: 오직 `currentSchedule.newConceptIds`로만 생성하여 학습 탭에서는 언제나 해당 회차의 신규 문항만 렌더링합니다.
  - `examCards`: 시험 탭 진입, 회차 변경, `[시험 리셋]`, `[시험 다시보기]` 호출 시마다 `sampleRandomIds(currentSchedule.learnedPoolIds, currentSchedule.reviewConceptCount)`를 새로 실행하여 매번 새로운 복습 3문항을 뽑고 신규 문항과 합쳐 셔플합니다.
